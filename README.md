# AssignMate Showcase

Interactive browser-only MVP for the 29 October 2026 showcase.

Open https://lawtszwah.github.io/assignmate-showcase/ to try the demo. No account or installation is required.

## Included files

- `index.html`: the self-contained AssignMate prototype, copied unchanged from the team's main branch (source blob `bb59bc2b488344df701adc916caecdcb491b76d2`, retrieved 26 October 2026).
- `.nojekyll`: serves the HTML directly on GitHub Pages.
- This README: deployment and demo notes.

The page uses optional Google Fonts and system-font fallbacks. No build process, Flask server, SQLite database or API is required.

## Demo notes

Create an assignment, review and adjust the plan, then start, pause, resume or complete tasks. Plans, progress and optional nicknames are stored in the current browser on this device only. Reloading restores saved plans; private browsing, changing browsers or clearing site data can remove access to them. Use Clear saved data in Today to reset.

There are no real accounts, cross-device sync or live group sharing. Any example people and activity are fictional. Use fictional assignment details for demonstrations.

## Deployment

GitHub Pages: deploy from the `main` branch, `/ (root)` folder. Keep this showcase repository separate from the course repository; only the demo page is included. Original course documents, interview records, backend files and commit history are excluded.
